# Инструкция: запуск презентации в Overleaf

Все файлы проекта находятся в папке `slides/M1P_Final_Dementyev/`.

---

## Шаг 1 — Создать проект в Overleaf

1. Открыть [overleaf.com](https://www.overleaf.com) → **New Project → Blank Project**
2. Дать имя, например: `Dementyev_MIPT68_2025`

---

## Шаг 2 — Загрузить файлы

Загрузи следующие файлы в **корень** проекта (не в подпапки):

| Файл | Откуда взять |
|------|-------------|
| `main.tex` | `slides/M1P_Final_Dementyev/main.tex` |
| `refs.bib` | `slides/M1P_Final_Dementyev/refs.bib` |

Кнопка загрузки в Overleaf: **Upload** (иконка стрелки вверх в левой панели).

---

## Шаг 3 — Создать папку `pictures` и загрузить изображения

В Overleaf:
1. Нажать **New Folder** → назвать `pictures`
2. Загрузить в эту папку два файла с твоими графиками:

| Имя файла в Overleaf | Что это |
|---------------------|---------|
| `cosine_t0.pdf` | Гистограмма косинусных расстояний при $t=0$ |
| `cosine_t5.pdf` | Гистограмма косинусных расстояний при $t=5$ |

> **Формат:** предпочтительно `.pdf` или `.eps` (векторные).
> Если графики ещё не готовы — временно используй `.png`, изменив расширения в
> `main.tex` (строки `\includegraphics{pictures/cosine_t0.pdf}`).

### Требования к графикам (из гайда)
- Оси подписаны: X — `cosine distance`, Y — `density`
- На графике `t=0`: стрелка с подписью *«Однородная аудитория»*
- На графике `t=5`: стрелка к пику $d \approx 0$ с подписью *«Коллапс различий»*
- Шрифт осей: `labelsize=14`, `ticklabelsize=12`

Пример кода Python для сохранения в нужном формате:
```python
import matplotlib.pyplot as plt

plt.rcParams.update({
    "text.usetex": True,
    "font.family": "serif",
    "axes.labelsize": 14,
    "xtick.labelsize": 12,
    "ytick.labelsize": 12,
})

# ... (построй свой график) ...

plt.savefig("cosine_t0.pdf", dpi=300, bbox_inches="tight")
plt.savefig("cosine_t5.pdf", dpi=300, bbox_inches="tight")
```

---

## Шаг 4 — Настроить компилятор

В Overleaf: **Menu** (кнопка сверху слева) → **Compiler** → выбрать **XeLaTeX**

> Без этого шага проект не скомпилируется: `fontspec` и русский язык требуют XeLaTeX.

---

## Шаг 5 — Скомпилировать

Нажать **Recompile**. При первом запуске Overleaf автоматически:
- Запускает XeLaTeX
- Запускает BibTeX (библиография)
- Повторно запускает XeLaTeX (для разрешения ссылок)

Если библиография не появилась — нажать **Recompile** ещё раз.

## Возможные ошибки и решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Font "Times New Roman" not found` | Компилятор не XeLaTeX | Menu → Compiler → XeLaTeX |
| `File 'utopia.sty' not found` | Нет пакета utopia | Закомментировать строку `\usepackage{utopia}` в main.tex |
| `File 'cosine_t0.pdf' not found` | Нет файла в `pictures/` | Загрузить файл или временно заменить на `.png` |
| Библиография не отображается | BibTeX не отработал | Нажать Recompile ещё раз |
| Заголовок слайда обрезан | Слишком длинный фрейм-титул | Уже решено через `\setbeamerfont{frametitle}{size=\small}` |

## Математическая нотация (напоминание)

Ключевое исправление относительно [Veprikov et al., 2025]:

- **Оператор сжатия:** $M_k = \Sigma_k(\Sigma_k + \lambda I)^{-1}$, его спектральный радиус $\rho(M_k) < 1$
- **Якобиан:** $W_k$ стремится к нулю по норме: $\|W_k\| \to 0$ (но сам не является оператором сжатия)
- Это различие отражено в слайдах 6 и 7
