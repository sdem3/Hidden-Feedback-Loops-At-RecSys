# Слайды защиты

Презентация для защиты ВКР: доклад ~7 минут + ~5 минут вопросов.

## Файлы

- `defense.pdf` — итоговая версия презентации.

## Правила оформления (МФТИ)

- Один слайд — одна мысль.
- На каждом слайде укажите номер: «текущий / всего».
- В заголовке — основной тезис слайда, не общая тема.
- Все обозначения, формулы и метрики совпадают с текстом ВКР (`../paper/`).

## Структура (рекомендуемая)

1. Титул: тема, автор, научный руководитель.
2. Актуальность и постановка задачи.
3. Математическая модель (краткая).
4. Главные теоремы.
5. Численные эксперименты — основной результат.
6. Эксперименты на MovieLens.
7. Управление: anti-collapse интервенции.
8. Выводы и направления дальнейшей работы.
